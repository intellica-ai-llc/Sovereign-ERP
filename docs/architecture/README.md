# Architecture

The architecture is documented with [arc42](https://arc42.org) in `arc42.md`: a single self-contained file, versioned by git history.

**Note on this checkpoint:** the copy of `arc42.md` here is **v0.8**, the version available when this checkpoint was assembled. If you have a newer version, replace this file with it. Evidence-backed corrections to apply to any version are listed in [`arc42-amendments.md`](arc42-amendments.md).

Decisions with lasting consequences also exist as individual records in [`../adr`](../adr). arc42 section 9 numbers (ADR 002, ADR 046, ...) are the architecture series; `eng-NNNN` records cover how this repository is built and run.
